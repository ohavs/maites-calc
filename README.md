# Maite's Calc — אפליקציית חישוב עלויות ותמחור למאפים וקינוחים 🧁

אפליקציית אנדרואיד מודרנית שנבנתה במיוחד עבור עסקים קטנים בתחום האפייה, הקונדיטוריה והקינוחים.
האפליקציה מאפשרת ניהול חומרי גלם, הרכבת מתכונים עם חישוב עלות עצמית בזמן אמת, משיכת מוצרים מ-API חיצוני, ניהול הזמנות בכמויות והחלפת פלטות צבעים דינמית.

---

## 🌟 תכונות עיקריות

### 📦 ניהול מצרכים וחומרי גלם
- הזנת מצרכים עם שם, מותג, קטגוריה ויחידת מידה (ק"ג, גרם, ליטר, מ"ל, יחידה וכו').
- הזנת מחיר אריזה וגודל אריזה — חישוב אוטומטי של מחיר ליחידת בסיס.
- **עדכון מחיר מצרך מעדכן מיידית ובאופן אוטומטי את כל המתכונים** שמשתמשים בו!
- סינון מהיר לפי קטגוריות וחיפוש טקסט חופשי.

### 🌐 משיכת מוצרים מ-Open Food Facts API
- חיפוש מוצרים ישירות ממאגר המזון העולמי לפי שם או ברקוד.
- ייבוא בלחיצה אחת עם מילוי אוטומטי של שם, מותג, קטגוריה ותמונה.
- אפשרות לעריכה והשלמת פרטים לאחר הייבוא.

### 📋 הרכבת מתכונים ותמחור בזמן אמת
- הוספת מצרכים מתוך המלאי האישי עם כמויות חופשיות והמרת יחידות מידה מדויקת.
- חישוב אוטומטי של עלות כוללת ועלות למנה / יחידה בודדת לפי תפוקת המתכון.
- סליידר אחוז רווח מבוקש (0%–200%) המציג בזמן אמת את מחיר המכירה המומלץ והרווח הצפוי.
- פירוט מלא של עלות כל מצרך בתוך המתכון.

### 🛒 ניהול מכירות והזמנות בכמויות
- יצירת הזמנות מותאמות אישית עם בחירת מנות מהמתכונים.
- קביעת כמויות ומחירי מכירה ליחידה.
- חישוב רווח נקי, סה"כ הכנסה ועלות עצמית כוללת של ההזמנה.
- ניהול סטטוסי הזמנה (טיוטה, מאושר, בהכנה, הושלם, בוטל).

### 🎨 מערכת פלטות צבעים דינמית
- 6 ערכות צבעים מעוצבות בהשראת עולם האפייה והעיצוב המודרני:
  - 🍋 **ליים (ברירת מחדל)**: אלמנטים מודרניים בולטים על רקע כהה.
  - 🧁 **ורוד מאפה**: סגול-כהה עמוק עם ורוד פסטל חם.
  - 🍫 **שוקולד**: חום-זהב עשיר.
  - 🌊 **תכלת**: כחול נייבי עם תכלת בוהק.
  - 🍊 **תפוז**: שחור-פחם עם כתום חם.
  - ☁️ **לבן קלאסי**: עיצוב יום נקי עם סגול.
- בחירת הפלטה נשמרת ב-DataStore ומוחלת מיידית על כל רכיבי האפליקציה!

### 📱 חוויית משתמש ועיצוב
- **RTL מלא בעברית** עם פונט **Heebo** מבית Google Fonts.
- אלמנטים גדולים, מעוגלים ומרווחים (כרטיסים 24dp, כפתורים 16dp).
- דיאלוגי אישור לפני מחיקה (`ConfirmDialog`) ואזהרת יציאה ללא שמירה (`UnsavedChangesDialog`).
- תמיכה בהתחברות Google Sign-In וכניסה מיידית כאורח.

## 🛠️ ארכיטקטורה וטכנולוגיות

- **UI**: Jetpack Compose + Material 3
- **שפה**: Kotlin 2.x
- **ארכיטקטורה**: MVVM (Model-View-ViewModel) עם StateFlow
- **מסד נתונים וענן**: Firebase Firestore (סנכרון בזמן אמת + תמיכת אופליין)
- **אימות**: Firebase Authentication (Google Sign-In + Anonymous Auth)
- **רשת**: Retrofit + Gson (Open Food Facts API)
- **תמונות**: Coil Compose
- **העדפות מקומיות**: Jetpack DataStore Preferences
- **ניווט**: Jetpack Navigation Compose

## 🚀 הרצה והתקנה

```bash
# שכפול הפרויקט
git clone https://github.com/ohavs/maites-calc.git
cd maites-calc

# הרצת בדיקות יחידה
./gradlew testDebugUnitTest

# בניית קובץ APK
./gradlew assembleDebug
```
קובץ ה-APK נמצא תחת: `app/build/outputs/apk/debug/app-debug.apk`.
